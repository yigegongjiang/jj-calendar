# jj-calendar

macOS 日历 + 提醒事项查看器 + 快速录入 / 微调.

## 核心要求 (MUST)

- 写入 = 快速录入 / 微调入口, 只在用户操作时写; 字段仅 类型 / 标题 / 日历 (列表) / 全天 / 时间 / 提醒完成 + 删除; 备注 / 闹钟 / 重复规则 / 地点 / 参与人等 MUST NOT 加 (去系统 App)
  - 不可写: 只读日历 (订阅 / 节假日 / 生日) + 他人组织的会议 (改动会同步给参与人); 不出现编辑入口
  - 重复日程只改 / 删本次 (`.thisEvent`); 重复提醒无 span, 作用于整个系列; 写前按 id 重新读取目标
  - Debug 构建写入限测试白名单 (`CalendarStore+Write`: iCloud 账户下精确标题), 不符即中止
- 只为「方便查看日程」定制; 紧凑, 最大化利用屏幕; MUST NOT 复刻系统日历
- 系统日历 / 提醒事项变化自动刷新; MUST NOT 依赖手动刷新
- 长期运行稳定: 无崩溃 / 泄漏 / 性能劣化; 数据读取 MUST NOT 阻塞 UI
- 主线程耗时只随视口增长: 视口附近的行先建, 其余分批补建; 内容未变的行不重建; 查询 MUST 有边界 (时间区间 / 仅未完成; NEVER `predicateForReminders(in:)`)
- 滚动 MUST NOT 重绘: 每行 = 单视图 + 一张位图 (NEVER 每格 / 每条一个 NSView; AX 用虚拟元素), 后台线程渲染; 仅视口附近的行持有位图
- 所有行为 MUST 通过 accessibility 透出自动化控制节点, 后台可完整操作; Debug 实例启动 + 操作 MUST NOT 干扰人类
- 不过度设计

## 架构

- Swift 6 + AppKit, macOS 14+, 纯代码 UI; NEVER SwiftUI; 无第三方依赖
- 新增按钮 / 开关统一放标题栏右侧 (`MainViewController.titlebarAccessory` stack); 例外: 授权提示按钮 (仅缺权限时) / 只显示「还原」按钮 (仅只显示中) 在工具栏筛选按钮旁
- 筛选面板: 核心操作 = 只显示 (仅作用于当前页签); 还原点持久化, 重启后可还原; 只显示中: 页签横幅 + 该行常驻还原 + 工具栏还原; NEVER 加回全部显示 / 全部隐藏
- 筛选面板: 日历 / 提醒事项分页签独立控制; 每页签整源开关 (关闭 = 主界面不显示该源, 列表勾选不变); 按账户分组 + 搜索 + 整行点击; 「只显示 / 还原」常驻每行右侧固定宽度列 (所有行同一 x, 不随标题 / 状态漂移); 「忽略」悬停才显示 (仅切透明度, 常驻无障碍树); 高度受屏幕限制, 超出滚动
- 提醒事项: 列表与日历同等参与筛选 / 忽略; 截止日落格 (无时刻 = 全天), 无截止日期不展示; 已完成按完成时间取区间内; 日历 / 提醒事项分别授权, 缺一不影响另一方
- 日期格放不下: 该列末行改为「+N 项」; 点击日期格 / 条目 / +N -> 当日完整列表 (popover, 文本可复制); 同日再点关闭
- 持久化: `~/.config/jj-calendar/` (Debug: `.app` 同级 `debug-config/`, 每份构建独立); 菜单 Settings… (⌘,) -> Finder 打开该目录; 启动读取; 缺失键取默认; 解析失败停写该文件 + 窗口副标题提示
  - `config.jsonc`: 界面选项 (时长 / 每行天数 / 字号 / 忽略背景色); 逐键中文说明; 界面操作时整文件重写; 手工编辑 (JSON5) 重启生效
  - `config.default.jsonc`: 全部键默认值 + 说明, 启动刷新, 仅供查阅
  - `state.json`: 界面状态 (隐藏 / 忽略日历 / 只显示还原点 / 整源开关 / 筛选页签 + 折叠分组 / 窗口位置 / 上次新建所用日历 + 列表)
- MUST NOT 使用 `UserDefaults` / `setFrameAutosaveName`; 用户可理解的选项 -> `AppConfig` + `configNotes`, 其余 -> `AppState`
- 颜色 MUST 跟随系统日历 / 系统色; NEVER 做颜色配置
